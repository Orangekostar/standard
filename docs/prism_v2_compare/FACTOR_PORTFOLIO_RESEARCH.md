# 因子与板块的收益/回撤搜索

固定12组：三种候选排序×是否按20日波动率降低仓位×是否板块分散。原趋势回踩、板块20日动量>0、市场/板块宽度≥50%、4%止盈、3%止损、5日到期、最多3只及交易成本/资金/成交限制不变。没有历史可验证JEV输入，不调用JEV。

- SCORE：原综合分S。
- LEADER：0.4S+0.3R+0.3B。
- DEFENSIVE：0.3S+0.2R+0.2B+0.3L。
- R=50+25×(F04+F05)，因子先裁剪到[-1,1]，分别是相对板块/市场20日风险调整强弱。
- B=25+25×tanh(板块20日对数动量/0.1)+50×板块宽度。
- L=100×(1−clip(Q02/0.04,0,1))，Q02为20日收益波动率。
- 波动率仓位系数min(1,0.015/Q02)，乘以前日NAV/3及原市场状态系数，且仍受现金与ADV限制；缺数不买，不加杠杆。
- D1：各板块仅保留最高分候选，再按分数排序；新买不得重复幸存持仓/同批计划的板块，实际成交后也复查，卖出失败不会自动放行同板块新买。后续板块归属变化不触发强制清仓。
