# 环境过滤与收益稳定性研究

本轮沿用主板非ST研究股票池、F0三日分数和原实际资金账本，研究环境过滤及买入额度是否改善跨时段稳定性。没有JEV调用或生产启用。

## 固定方案

- 12组：板块20日动量为正、市场与板块宽度均至少50%、两者同时满足；分别搭配RANGE新买额度50%或100%，计划最长持有5或10个交易日。
- 入场仍为加强版趋势回踩；止盈4%、止损3%，收盘信号、下一可成交开盘执行。最多3只，保留T+1、现金、涨跌停、停牌、原费率和价格取整。
- 缩放只针对新买入预算，不强制卖出或调整已有持仓；每笔还受实际现金及前信号日ADV20的1%限制。
- 原10日趋势回踩作为固定对照，不参与候选排名。
- 六个连续63交易日筛选窗口：2024-08-21至2026-03-18。每种成本均要求至少5/6窗口盈利、均值为正、最差窗口不低于−3%、最大窗口回撤不超过10%、至少60笔平仓及40个成交日。
- 在合格者中先比较两种成本下较弱的季度收益25%分位数，再比较较弱均值、较小回撤和固定ID。
- 冻结一个选择后，仅复核该对象及固定对照，后段为2026-03-19至2026-06-25、2026-06-26至2026-09-28两个独立66日窗口。每窗口、每成本均要求正净收益、回撤≤10%、至少10笔平仓和10个成交日。
- 没有初筛合格对象时，仅复核同一预定排序的诊断对象，不能因其后段盈利而改判成功。不得看后段结果再换候选。
- 每窗口/成本独立100万元；末11个交易日停止新买。任何未平仓均不合格，未实现损益仍反映在净值。平均窗口收益不是连续复利收益。
